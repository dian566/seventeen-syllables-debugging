Second entry for the make.fun bounty "Seventeen Syllables of Debugging" — a haiku about debugging, 5-7-5 syllables. This one is the Heisenbug: the bug only appears when nobody is watching, and the print statement you add to catch it scares it away.

Run `python3 main.py` to write the haiku to `/output/entry.txt`.
